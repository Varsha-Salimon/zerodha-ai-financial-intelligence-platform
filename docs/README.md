# Zerodha AI Financial Intelligence Platform

## Objective

An AI-powered portfolio intelligence platform that analyzes investment portfolios using market data, analytics, and AI to generate explainable insights and recommendations.

## Tech Stack

Frontend:
- Next.js
- React
- Tailwind CSS

Backend:
- FastAPI
- Python

AI:
- Gemini API

Database:
- PostgreSQL

Deployment:
- Vercel
- Render
